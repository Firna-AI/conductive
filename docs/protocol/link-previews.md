# Public link previews

The public marketing pages provide Open Graph and Twitter card metadata
so that a shared link can show a product preview.
This includes the home page, guides, legal pages, and comparison page.

- Each page uses its own title and description.
- A page without a description omits the description metadata.
- Each page identifies its own address on the product's public site.
- The image address is absolute and uses HTTPS.
- The image is publicly accessible without sign-in.
- The image has a width of 1200 pixels and a height of 630 pixels.
- The image shows the approved light-blue painting, the brand at the
  top left, the bold homepage headline, and the centred app cropped at
  the bottom, with equal side margins.
- The image metadata includes its type, dimensions, and descriptive
  alternative text.
- Twitter cards request the large-image layout.
- Not-found pages, sign-in agreement pages, and GitHub install return
  pages do not advertise a public sharing card.

The user approved the image and its use for link previews on 10 November
2026. A single approved image identifies the product across the public
pages. Page-specific artwork is unnecessary for this release.

Social services choose how they display and cache the preview.
The metadata cannot require a service to refresh an existing card.
