Conductive brings agents powered by Claude and Codex into workspaces with their own cloud computers. Follow the conversation beside your files, changes, terminal, and previews.

## New

- Open New workspace as a dialog over the current screen, with a new choice in Preferences.
- New workspaces take their names from your first message.
- Move session, file, and diff tabs by dragging them or using their menus.
- A new org prepares its first cloud computer automatically after you choose its repositories.
- Agents can find repositories, sections, and models in workspaces from a new cloud computer build.
- Agents can name the workspaces they create after a new cloud computer build.
- In the Mac app, receive updates and check for them from the Help menu.
- Open Conductive's public source repository from the website header.

## Improved

- Set the default model and effort for new workspaces in Preferences.
- Press Enter to send from any message box on a computer, or Shift+Enter to add a line.
- Finished agent work folds into one line, with the answer and expandable steps still available.
- The message box keeps its position across sessions and names another member's login when your message uses it.
- The Terms and Privacy pages are complete, with the ways to make a legal or privacy request.

## Fixed

- A failed first start keeps your workspace and queued messages, with Try again to continue in the same place.
- The command palette shows loading and retry states when workspace or repository data is unavailable.
- Reopened New workspace drafts place the cursor at the end of your text.
- GitHub App installation returns your browser to the screen where you started.
- In the Mac app, GitHub App installation explains how to return to Conductive.
- Dismissing a dialog without leaving the page returns keyboard focus to its control.
- In workspaces from a new cloud computer build, Claude keeps answering new messages when earlier background results arrive.
