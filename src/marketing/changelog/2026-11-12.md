Connect Claude or Codex to a model endpoint that you choose. Diffs now show syntax colours, and long chats bring the newest messages into view first.

## New

- Connect Claude or Codex to your own endpoint in workspaces from a new cloud computer build.
- Diffs show syntax colours in light and dark themes.
- Copy a workspace link from its row menu, or a session link from its tab menu.
- Resize the split between file lists and Terminal or Preview, with your choice saved for the next visit.
- Agents can manage workspaces, sessions, sections, and private previews in workspaces from a new cloud computer build.
- When an agent stops a turn, the chat shows "Stopped from" with a link to its session.
- All files includes attachments and agent notes in workspaces from a new cloud computer build.
- Mention those attachments and notes with @ in workspaces from a new cloud computer build.
- Close a preview from its own tab, including a tab that is not selected.

## Improved

- Long chats show their newest messages first, then load earlier messages above them.
- Sent messages appear at once, and the message box clears while the send finishes.
- Click a workspace in the sidebar to start typing in its message box.
- Workspace marks show a clearer working light and keep moving while pull request checks run.
- Menus show clearer hover and keyboard focus in dark mode, with a pointer cursor on available actions.
- Model pickers follow updates to your own endpoint's model list, including changes made while Account is open.

## Fixed

- Opening a stopped workspace shows Starting and the message box while its cloud computer resumes.
- File tabs show the file's name after it opens, including attachments absent from the file lists.
- Archiving the open workspace keeps the Archived group open or collapsed as you chose.
- Codex on a ChatGPT plan connects more reliably and keeps long answers streaming.
- A failed Codex message names the model that could not run.
