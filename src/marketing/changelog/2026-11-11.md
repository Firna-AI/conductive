The pull request bar helps you take work from local edits through review and merge. Continue starts the next task in the same workspace, with your files and conversations kept.

## New

- Ask the agent to create a pull request or commit and push from the pull request bar.
- Use Fix checks, Resolve conflicts, or Address review to ask the agent for the next change.
- Merge a pull request from its bar using your GitHub account and the repository's merge rules.
- After a merge, Continue starts a branch from the latest default branch and keeps your workspace, files, and sessions.
- Use keyboard shortcuts for workspace actions, with keys shown in the command palette and tooltips.
- Change your keys in Account's Keyboard shortcuts tab, with your choices saved across browsers and the Mac app.
- Connect Codex to a ChatGPT plan for workspaces from a new cloud computer build.
- Send feedback and screenshots from the command palette.
- Drop files into chat or New workspace, or attach them at the cursor as chips inside your text.
- Open an attached file from its chip in a sent message.
- PNG, JPEG, GIF, and WebP files show as pictures up to 5 MiB.
- Agent messages show Markdown headings, with matching heading sizes in file previews.
- Open a session directly from its link, with session links shown as chips in chat.
- Agents can create and message sessions across your org in workspaces from a new cloud computer build.
- Agents can read session transcripts across your org in workspaces from a new cloud computer build.
- Claude keeps the conversation open for background results in workspaces from a new cloud computer build.
- Shared website links show a Conductive preview image with the page's title and description.

## Improved

- Workspace marks show check results and merged pull requests in colour, with motion for agent activity.
- Merged pull request bars and Continue use purple in light and dark themes.
- Long chats load in fewer steps, and the message box appears while session history loads.
- Large previews open faster, and repeat visits reuse files when the previewed app allows it.
- Open Cloud computer settings from New workspace while its build runs.
- The model picker uses a small icon for models that open a new session.
- In workspaces from a new cloud computer build, chat steps show tool names with their details.
- Agents can use the browser with fewer interruptions in workspaces from a new cloud computer build.
- Account shows when sign-up is open.

## Fixed

- The pull request bar and Checks stay current more reliably when repositories have many workspaces.
- Chat reads and messages stay responsive while a cloud computer starts.
- The latest group of tool calls stays open while the agent works, with earlier groups folded.
- Automatic workspace names use spaces in place of underscores.
- In workspaces from a new cloud computer build, All files and Changes keep updating after a saved computer starts.
- After the next cloud computer start, agent pushes keep working with the account that sent the task.
- In workspaces from a new cloud computer build, GitHub access failures give clearer recovery steps.
- In the Mac app, a click on a top bar closes an open menu.
